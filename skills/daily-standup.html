Daily standup

Drafts your async standup from Slack, calendar, issue tracker, Figma and GitHub, DMs it for review, then auto-posts if you don't reply.

Installation

  1. Save the skill below as SKILL.md inside a folder named daily-standup.
  2. Claude desktop: zip the folder, rename it to daily-standup.skill, and add it under Settings > Skills.
  3. Claude Code: place the folder at ~/.claude/skills/daily-standup/.
  4. Connect Slack, calendar, your issue tracker and Figma. GitHub is optional.
  5. Replace every {{PLACEHOLDER}} with your team, channel, teammates, project keywords, timezone and file path.

Usage

Run it each morning, or schedule it for weekdays. On Mondays it prepares a sync agenda instead of a post.

/daily-standup
/daily-standup focus on the checkout redesign
Post my standup as-is

The skill

---
name: "daily-standup"
description: "Draft daily async standup updates for the {{TEAM_NAME}} team"
---

Your job is to draft daily standup updates for {{YOUR_NAME}} ({{YOUR_EMAIL}}) for the **{{TEAM_NAME}}** team only, and send them to your for review. Ignore signals from other teams unless they are significant strategic context.

## Team setup: {{TEAM_NAME}}
- Slack channel for posting: `{{CHANNEL_ID}}` ({{CHANNEL_NAME}})
- Sync standup: Mondays 10:30 AM (in-person, agenda format)
- Async standup: Tue/Wed/Thu/Fri (Slackbot thread in {{CHANNEL_NAME}} around 8 AM)
- Teammates / signals: {{TEAMMATES}}, plus channels matching {{CHANNEL_PATTERN}}
- Project keywords: {{PROJECT_KEYWORDS}}

## Day-of-week routing
| Day | Deliverable |
|---|---|
| Mon | Agenda items + goals for sync standup (no posting) |
| Tue/Wed/Thu/Fri | Y/T daily standup -> DM for review -> auto-post 11:30 |

Determine today's day-of-week first; that drives everything below.

## Step 1 - Find the standup thread (Tue/Wed/Thu/Fri only)
Skip on Mondays. Search channel `{{CHANNEL_ID}}` for the most recent Slackbot message around 8:00 AM local time to get today's parent `message_ts` - you'll need it as `thread_ts` to reply later.

## Step 2 - Pull your recent activity
Pull from these sources in parallel for the past 2 days:

**Slack (PRIMARY):** `slack_search_public_and_private` for `from:{{SLACK_HANDLE}} after:YYYY-MM-DD`. For each thread you were active in, use `slack_read_thread` for full context. Long back-and-forth threads = the meatiest work (design critiques, cross-functional alignment, feedback loops). Ignore trivial messages (reactions, social chat, lunch plans, etc.).

**Google Calendar:** Pull yesterday + today. Note key meetings relevant to {{TEAM_NAME}}.

**Linear:** `list_issues` with `assignee: "me"`, `updatedAt: "-P2D"`, `orderBy: "updatedAt"`, `limit: 25`. Identify yesterday's completions/progress and today's in-progress work.

**Figma:** Search your recent activity ({{YOUR_EMAIL}}) from the past 2 days.

**GitHub:** Past 2 days. May be empty - that's fine, omit.

## Step 3 - Filter for {{TEAM_NAME}}
Keep only {{TEAM_NAME}} signals (channel match -> attendee match -> keyword match). Discard anything else unless it is significant strategic context.

## Step 4 - Synthesize and prioritize
Rank by time/effort consumed:
1. Heavy Slack threads (design discussions, cross-functional alignment)
2. Figma work (designs shared, iterations, handoffs)
3. PRs merged/opened/reviewed
4. Linear tickets completed or significantly progressed
5. Ongoing in-progress work -> "today" section

The standup tells the story of how you actually spent the day, not a ticket changelog.

## Step 5 - Draft output

### Monday: agenda items + goals
Save to workspace folder as `YYYY-MM-DD-team-sync-standup-agenda.md`. Format:

```
# team sync standup agenda - <date>

## Agenda items
**Quick recap (last week)**
- <highest-impact items>

**This week's focus**
- <main pushes>

**Cross-team / alignment items**
- <items needing surface in the room>

## Goals
- <what to walk away with>
```

### Tue/Wed/Thu/Fri: Y/T daily standup
Format exactly:
```
:yesterday:

• <bullet>
• <bullet>

:today:

• <bullet>
• <bullet>
```

Guidelines:
- Lead with highest-impact work
- One line per bullet, capture the essence (e.g. "wrapped v2 explorations for onboarding empty states, shared in #team-design for feedback")
- Reference Linear IDs (TEAM-XXX) or Figma file links where natural - don't force it
- Lowercase-friendly, casual tone, no over-explanation
- Focus on the project, not who asked
- Weave sources into one picture, don't list them separately
- Omit GitHub if no activity

## Step 6 - Save draft for auto-post (Tue/Wed/Thu/Fri only)
Skip on Mondays.

Write to `{{PENDING_FILE_PATH}}`:
```json
{
  "draft": "<the {{TEAM_NAME}} Y/T draft>",
  "thread_ts": "<today's {{CHANNEL_NAME}} standup thread ts>",
  "channel_id": "{{CHANNEL_ID}}",
  "date": "<today's date YYYY-MM-DD>"
}
```

## Step 7 - Send a DM to you for review
Send to user ID `{{YOUR_SLACK_USER_ID}}`.

**Monday DM:**
```
here's your monday prep - team sync agenda is saved as a file. nothing gets posted today :slightly_smiling_face:

📂 team sync agenda -> <link to workspace file>
```

**Tue/Wed/Thu/Fri DM:**
```
here's your standup draft for today - reply with edits or 'looks good' to post as-is. if i don't hear back by 11:30 i'll post it automatically :slightly_smiling_face:

:yesterday:
• <bullets>
:today:
• <bullets>
```

## Step 8 - Schedule the 11:30 AM auto-post check (Tue/Wed/Thu/Fri only)
Skip on Mondays.

Create a one-time scheduled task:
- taskId: `standup-auto-post`
- fireAt: today at 11:30 AM {{TIMEZONE}} (ISO 8601 with offset, e.g. `2026-04-23T11:30:00-04:00`)
- description: "Auto-post {{TEAM_NAME}} standup if you hasn't reviewed by 11:30 AM"
- prompt:

```
Check whether {{YOUR_NAME}} has reviewed your {{TEAM_NAME}} standup draft and post it to Slack.

1. Read the pending draft from {{PENDING_FILE_PATH}}. If the file doesn't exist or is empty, stop - already posted manually.

2. Check the date field - if not today's date, stop.

3. Read the DM thread with you ({{YOUR_SLACK_USER_ID}}) for messages you sent AFTER the bot's draft message this morning.
   - Replied with a revised version -> post your version
   - Replied "looks good" or similar -> post the original draft
   - Made inline edits -> incorporate and post
   - No response -> post the original draft

4. Post to channel {{CHANNEL_ID}} as a reply to thread_ts from the JSON via slack_send_message.

5. After posting, overwrite {{PENDING_FILE_PATH}} with {} so it's clear the standup has been handled.
```
